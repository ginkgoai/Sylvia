# Quarentena

Esta área preserva material que não deve alimentar RAG, prompts de abertura ou decisões atuais.

- `Duplicatas-Confirmadas/`: cópias idênticas preservadas por segurança.
- `Legado-Nao-Validado/`: documentos antigos, prompts, exportações e planos que podem contradizer o estado atual.
- `Sensivel-ou-Restrito/`: material adulto, financeiro pessoal, credenciais potencialmente expostas ou conteúdo que exige escopo explícito.
- `Midia-Opaca/`: imagens, vídeos e anexos sem leitura/classificação; não são apagados nem analisados automaticamente.

Para promover um item, comparar com a fonte atual, registrar o veredito em `00_Cerebro/CONTEXT_LOG.md` e só então movê-lo para a pasta temática.
