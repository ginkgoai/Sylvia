# Configuração do Claude Design

## Nome do sistema

LEAF by Ginkgo — Marketing & Product Design System

## Descrição

Sistema visual do LEAF, agente inteligente de atendimento no WhatsApp. A identidade combina tecnologia premium, inteligência operacional, interfaces conversacionais e crescimento modular. O sistema será usado em campanhas Meta, conteúdo orgânico, landing pages, apresentações e interfaces React.

## Repositório de referência

https://github.com/ginkgoai/ginkgo-leaf-systems

Use o repositório como referência estrutural de React, TypeScript, shadcn/ui, Radix UI, Tailwind, Lucide e Motion. Não herde automaticamente a antiga paleta cyber/ciano.

## Notas para colar em “Any other notes?”

O arquivo DESIGN.md é a fonte principal de verdade deste sistema.

Caso exista conflito entre o DESIGN.md, os arquivos CSS existentes, os componentes do repositório ou as imagens de referência, priorize nesta ordem:

1. DESIGN.md
2. Logos e ativos oficiais
3. Cinco campanhas aprovadas
4. Componentes React do projeto
5. CSS legado

O CSS atual do repositório pode conter verde elétrico, ciano, glow intenso e uma atmosfera cyberpunk. Utilize apenas suas estruturas, padrões de componentes, glass cards e animações. Não reproduza automaticamente sua antiga paleta.

A identidade final deve ser premium, escura, empresarial, futurista, confiável, modular e tecnológica sem parecer gamer.

Paleta prioritária:
- preto;
- grafite;
- verde Ginkgo;
- esmeralda;
- branco;
- dourado discreto.

Evitar:
- excesso de neon;
- ciano dominante;
- robôs humanoides genéricos;
- cérebros digitais clichês;
- mãos robóticas;
- circuitos aleatórios;
- fundos excessivamente carregados;
- estética infantil;
- visual genérico de startup;
- estética de criptomoeda;
- textos pequenos ou longos dentro das artes.

Todo conteúdo textual deve ser escrito em português brasileiro.

O LEAF nunca deve ser chamado de chatbot simples. Use:
- agente inteligente;
- agente de atendimento;
- agente operacional;
- funcionário digital;
- infraestrutura inteligente de atendimento.

Criar componentes React reutilizáveis em TypeScript, utilizando Tailwind CSS, shadcn/ui, Radix UI, Lucide e Motion.

Os componentes devem funcionar em:
- campanhas para Facebook;
- campanhas para Instagram;
- landing pages;
- páginas de vendas;
- demonstrações interativas;
- dashboards do produto.

Para campanhas sociais, trabalhar primeiro em 1080 × 1350 px.

Cada peça deve conter:
- uma ideia principal;
- uma headline;
- no máximo quatro benefícios;
- um único CTA;
- alta legibilidade em smartphone.

Nunca inventar:
- números;
- clientes;
- depoimentos;
- métricas;
- resultados;
- preços;
- selos;
- avaliações;
- integrações ainda não confirmadas.

O plano base deve parecer completo. CRM, agenda, voz, memória avançada, ERP, automações e múltiplos canais devem aparecer como expansão modular, não como correção de um produto incompleto.
