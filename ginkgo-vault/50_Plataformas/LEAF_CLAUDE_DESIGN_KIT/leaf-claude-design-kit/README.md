# LEAF by Ginkgo — Claude Design Kit

Pasta enxuta e pronta para anexar ao Claude Design como referência de design e frontend.

## O que anexar na tela de configuração

### GitHub
`https://github.com/ginkgoai/ginkgo-leaf-systems`

### Link code from your computer
Anexe esta pasta inteira: `leaf-claude-design-kit/`

### Add fonts, logos and assets
Anexe também os logos oficiais em SVG/PNG na pasta `assets/logos/` antes de enviar.

### Arquivos prioritários
1. `DESIGN.md`
2. `CLAUDE_DESIGN_SETUP.md`
3. `src/styles/tokens.css`
4. `src/components/leaf/`
5. `assets/reference-campaigns/`
6. `campaigns/30-DAY-CONTENT-PLAN.md`

## Fonte da verdade

Em qualquer conflito, use esta ordem:
1. `DESIGN.md`
2. Logos oficiais
3. Campanhas visuais aprovadas
4. Componentes React deste kit
5. CSS legado do repositório

## Observação

As cinco imagens em `assets/reference-campaigns/` são referências visuais de campanha, não arquivos oficiais de logo nem provas de produto real. Substitua mockups por capturas reais do LEAF quando disponíveis.
