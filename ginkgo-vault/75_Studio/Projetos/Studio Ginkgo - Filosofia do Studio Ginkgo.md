Um experimento humano.

- Computação quântica

- Tentativa de mapear todas as decisões humanas
- Projeto para eliminar incerteza
- Projeto para prever sofrimento

Prever tudo.  
Controlar tudo.  
Eliminar erro.

Mas não como esperavam.

Falhas humanas:

- Ego

- Ambição científica

- Ajustar probabilidades
