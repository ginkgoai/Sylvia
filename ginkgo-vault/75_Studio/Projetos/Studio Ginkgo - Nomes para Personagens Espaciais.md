## ⚙️ Dica de Direção Criativa

Para podcasts ou animações em loop:

- Misture **nomes curtos + símbolos** para IAs
- Use **sobrenomes conceituais** (Drift, Flux, Singularity) para humanos
- Para entidades antigas, sons **abertos e graves** (Umbra, Thalos, Zha’el)

Se quiser, posso:

- Criar **backstory + voz (ElevenLabs)** para cada personagem
- Montar **duplas filosóficas** para diálogos estilo *devaneio cósmico*
- Gerar um **universo narrativo fechado** (timeline, facções, conflitos)
