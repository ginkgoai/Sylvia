### 🧠 O que é o Butler no Trello

Butler é o **sistema de automação nativo do Trello**.  
Ele permite criar **regras, comandos e botões** que executam ações automaticamente com base em gatilhos.

Exemplo simples:

> “Quando um cartão for movido para a lista *Feito*, marque-o como concluído e adicione a data de conclusão.”

Pronto — nunca mais você vai precisar clicar manualmente em nada pra isso.

---

### ⚙️ Como ele opera na prática

O Butler trabalha em **quatro modos principais**:

1. **Regras (Rules)**  
	São automações *reativas*: quando algo acontece, ele reage.  
	Exemplo:
	- “Quando um cartão for movido para ‘Em Progresso’, adicione o rótulo *Trabalhando*.”
		- “Quando o prazo estiver a 2 dias, mencione o responsável.”
2. **Botões de Cartão (Card Buttons)**  
	São *botões personalizados* que você cria e aparecem em cada cartão.  
	Exemplo:
	- Um botão “Enviar para revisão” que move o cartão, adiciona um checklist e marca o revisor.
3. **Botões de Quadro (Board Buttons)**  
	São botões que aparecem no topo do quadro e executam comandos em lote.  
	Exemplo:
	- “Arquivar todos os cartões da lista *Concluído*.”
4. **Comandos de Agenda (Scheduled Commands)**  
	São tarefas agendadas.  
	Exemplo:
	- “Toda segunda-feira às 9h, mova todos os cartões da lista *A Fazer* para *Prioridades da Semana*.”

### 🔗 Integração com a IA e automações externas

O Butler pode se conectar com outros sistemas — e é aí que entra o seu plano de “Agenda Copiloto” com IA:

- **n8n ou Flowise** → Você pode fazer com que o Butler **dispare Webhooks**, ou reaja a Webhooks que você manda de outros agentes (por exemplo, um agente de IA que analisa prioridade e manda comando pro Trello).
- **Comandos via API** → O Butler responde a triggers do Trello, mas você pode orquestrar o fluxo completo com o Trello API + n8n para fazer a IA "pensar" e o Butler "agir".
- **WhatsApp / Evolution API** → Dá pra criar uma rotina tipo:  
	“O humano manda mensagem ‘adicionar tarefa x’ → IA interpreta e adiciona cartão via Trello API → Butler entra em ação com as automações internas.”

Em resumo: o Butler cuida da **execução mecânica**, enquanto a IA cuida da **interpretação e decisão**.

## 1\. ⚙️ Configuração básica de ferramentas

### 🧠 IA + n8n

- Use o **Flowise** (ou n8n direto) para criar o agente que interpreta as mensagens.
- Esse agente recebe algo como:
	> “Adicionar tarefa revisar contrato até sexta, prioridade alta.”
- Ele extrai **título**, **prazo**, **prioridade** e **responsável**.

Exemplo de nó:

- **Webhook (Trigger)** → recebe mensagem da Evolution API
- **OpenAI / Flowise Node** → interpreta texto e estrutura dados
- **Trello Node** → cria cartão com as informações

---

## 2\. 🗃️ Conexão com o Trello

No n8n:

1. Configure a credencial **Trello API Key + Token**.
2. Crie um **nó “Create Card”** com:
	- `boardId`: seu quadro principal
		- `listId`: “A Fazer” ou equivalente
		- `name`: título da tarefa (ex: “Revisar contrato”)
		- `desc`: detalhes (pode vir da IA)
		- `due`: data extraída (ex: `2025-10-20`)
		- `labels`: prioridade (ex: “Alta”)

Pronto, o cartão nasce dentro do seu quadro.

---

## 3\. 🤖 A mágica do Butler dentro do Trello

Agora entra o **mordomo**.

### 🧩 Regras automáticas úteis

1. **Organização automática**
	```markdown
	Quando um cartão é criado na lista “A Fazer” com o rótulo “Alta prioridade”,
	mova-o para o topo da lista.
	```
2. **Checklist padrão**
	```markdown
	Quando um cartão é criado,
	adicione o checklist “Fluxo padrão” com os itens: análise, execução, revisão.
	```
3. **Responsável automático**
	```markdown
	Quando o nome do cartão contém “revisar”,
	atribua ao membro Gabriel.
	```
4. **Follow-up**
	```markdown
	Dois dias antes do prazo, comente “Lembrete: prazo se aproxima!”
	e mencione o responsável.
	```
5. **Conclusão**
	```markdown
	Quando um cartão é movido para “Feito”,
	marque a data de conclusão e adicione o emoji ✅ no título.
	```

Essas regras podem ser criadas direto no **menu “Automations” > “Rules”** do Trello.

## 4\. 📲 Integração com WhatsApp (Evolution API)

### Fluxo de comunicação

1. **Entrada de mensagem**
	- O usuário (você) envia algo como:  
		“Tarefa nova: revisar contrato até sexta com o Pedro.”
		- Evolution API envia via Webhook para o n8n.
2. **n8n processa e responde**
	- A IA interpreta a mensagem e cria o cartão no Trello.
		- Depois, o n8n responde via WhatsApp algo como:  
		“Tarefa adicionada ao quadro *Projetos Ginkgo*, prazo 18/10, responsável: Pedro.”
3. **Notificações automáticas (opcional)**
	- Butler ou n8n pode enviar notificações de status:
		- “Tarefa concluída ✅”
				- “Prazo se aproxima ⏰”
				- “Pedro moveu a tarefa para revisão 🔄”
