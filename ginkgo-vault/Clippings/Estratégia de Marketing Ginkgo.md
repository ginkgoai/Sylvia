A estratégia faz sentido. Para uma operação de uma pessoa, o maior erro é tentar parecer uma agência grande. O objetivo inicial deve ser parecer uma empresa extremamente especializada.

A Ginkgo não deve vender "automação". Ela deve vender **infraestrutura de IA para empresas**. Esse posicionamento já diferencia a marca.

---

Transformar a Ginkgo em uma autoridade regional em IA aplicada para empresas.

Objetivos:

- Gerar confiança.
- Ensinar o mercado.
- Mostrar aplicações reais.
- Conseguir os primeiros contratos recorrentes.
- Alimentar campanhas pagas.

Não buscar viralização.

Buscar conversas.

## Identidade visual

Todos os materiais devem seguir um padrão consistente:

- Fundo escuro (grafite/preto).
- Verde Ginkgo como cor de destaque.
- Tipografia limpa (Inter + Space Grotesk).
- Poucos elementos por tela.
- Animações suaves.
- Linhas finas, vidro, metal e interfaces minimalistas.
- Sem robôs humanoides, cérebros brilhando ou clichês visuais de IA.
