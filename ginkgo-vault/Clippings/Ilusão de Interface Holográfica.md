O conceito do Reel é uma ilusão de interface futurista, no estilo "HUD holográfico", feita para parecer um display flutuando na frente do monitor. A mensagem "No CGI used..." normalmente significa que não foi adicionada em pós-produção tradicional; ainda assim, quase sempre existe algum recurso físico ou óptico envolvido.

Pelo quadro do vídeo, parece uma combinação de:

- Um painel transparente (acrílico ou vidro) posicionado à frente do monitor.
- Interface em tons de azul neon com elementos inspirados em HUDs de filmes de ficção científica.
- Iluminação controlada para esconder as bordas do painel.
- Sincronização entre a animação do monitor e o ponto onde a pessoa toca.
- Câmera fixa para preservar a ilusão de profundidade.

Para a Ginkgo, esse conceito pode evoluir muito além de um efeito visual.

### Aplicações

- Demonstrações do Leaf como se fosse um assistente holográfico.
- Dashboards do Pyre surgindo sobre a mesa.
- Interfaces da Wave para campanhas de marketing.
- Vídeos de lançamento de produtos.
- Reels mostrando "a IA trabalhando" em tempo real.

### Como reproduzir

Pipeline recomendado:

1. Blender para criar a interface 3D.
2. After Effects ou DaVinci Resolve Fusion para composições.
3. CapCut para edição rápida.
4. Figma para desenhar os componentes da UI.
5. Vidro/acrílico + monitor OLED para gravações práticas, caso queira um efeito físico.
