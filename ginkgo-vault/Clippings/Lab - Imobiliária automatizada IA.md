## 1) Deploy base (Docker Compose por serviços)

**Opinião curta**: use **Traefik** como proxy reverso + **Authelia** para SSO administrativo; **Portainer** opcional; **Watchtower** para auto-update (com parcimônia).

### Serviços mínimos

- **Reverse proxy**: Traefik
- **Banco**: Postgres 15+ com `pgvector`
- **Cache/Queues**: Redis
- **n8n**: orquestração
- **Flowise**: agentes / chains
- **Evolution API**: WhatsApp
- **Kokoro**: TTS (voz)
- **Whisper/ASR**: transcrição (pode ser OpenAI Whisper API ou local)
- **File storage**: Supabase (Cloud) — buckets, Auth, Postgres gerenciado **ou** S3 compatível (minio) + Keycloak (se quiser self-host extremo)

> Para acelerar, **Supabase Cloud** é excelente: Auth, Postgres (com pgvector), Storage e Realtime prontos.

### Esqueleto Compose (resumido)

```markdown
version: "3.9"
services:
  traefik:
    image: traefik:v3
    command:
      - "--providers.docker=true"
      - "--entrypoints.websecure.address=:443"
      - "--certificatesresolvers.le.acme.tlschallenge=true"
      - "--certificatesresolvers.le.acme.email=${LE_EMAIL}"
      - "--certificatesresolvers.le.acme.storage=/letsencrypt/acme.json"
    ports: ["443:443"]
    volumes: ["/var/run/docker.sock:/var/run/docker.sock","./letsencrypt:/letsencrypt"]
    restart: unless-stopped

  postgres:
    image: ankane/pgvector:latest
    environment:
      POSTGRES_PASSWORD: ${PG_PASSWORD}
      POSTGRES_DB: ginkgo_realty
      POSTGRES_USER: ginkgo
    volumes: ["pgdata:/var/lib/postgresql/data"]
    restart: unless-stopped

  redis:
    image: redis:7-alpine
    command: ["redis-server","--appendonly","yes"]
    volumes: ["redisdata:/data"]
    restart: unless-stopped

  n8n:
    image: n8nio/n8n:latest
    environment:
      N8N_HOST: api.ginkgorealtyhome.com
      N8N_PROTOCOL: https
      N8N_ENCRYPTION_KEY: ${N8N_KEY}
      QUEUE_BULL_REDIS_HOST: redis
      DB_POSTGRESDB_HOST: postgres
      DB_POSTGRESDB_DATABASE: ginkgo_realty
      DB_POSTGRESDB_USER: ginkgo
      DB_POSTGRESDB_PASSWORD: ${PG_PASSWORD}
    depends_on: [postgres, redis]
    labels: [ "traefik.enable=true", "traefik.http.routers.n8n.rule=Host(\`api.ginkgorealtyhome.com\`)" , "traefik.http.routers.n8n.tls.certresolver=le"]
    restart: unless-stopped

  flowise:
    image: flowiseai/flowise:latest
    environment:
      PORT: 3000
      FLOWISE_USERNAME: ${FLOWISE_USER}
      FLOWISE_PASSWORD: ${FLOWISE_PASS}
    labels: [ "traefik.enable=true", "traefik.http.routers.flowise.rule=Host(\`flow.ginkgorealtyhome.com\`)", "traefik.http.routers.flowise.tls.certresolver=le"]
    restart: unless-stopped

  evolution:
    image: atendai/evolution-api:latest
    environment:
      SERVER_URL: https://wa.ginkgorealtyhome.com
      AUTHENTICATION_API_KEY: ${EVOLUTION_KEY}
    labels: [ "traefik.enable=true", "traefik.http.routers.evo.rule=Host(\`wa.ginkgorealtyhome.com\`)", "traefik.http.routers.evo.tls.certresolver=le"]
    restart: unless-stopped
volumes: { pgdata: {}, redisdata: {}, letsecrypt: {} }
```

> Ajuste hosts e variáveis conforme teu ambiente. Kokoro/Whisper entram como serviços adicionais ou chamadas externas.

## 2) Modelo de dados (mínimo viável sólido)

**Tabelas núcleo**

- `owners` (proprietários)
- `properties` (imóveis)
- `units` (unidades dentro de um property, se aplicável)
- `assets` (mídias: fotos, vídeos, laudos PDF)
- `listings` (anúncios, status, preço)
- `leads` (captação, origem, funil)
- `inquiries` (contatos de interessados, mensagens)
- `tenants` (locatários)
- `contracts` (aluguel/venda; link para assinatura)
- `bookings` (temporada/reservas)
- `payments` (faturas, split comissão, liquidação)
- `inspections` (vistorias; imagens e checklist)
- `webhooks_log` (auditoria de eventos externos)
- `audit_log` (quem mudou o quê e quando)

**Campos chave**

- `properties`: id, owner\_id, tipo, endereço, geo (lat/long), área, quartos, banheiros, comodidades (JSONB), status, created\_at
- `listings`: property\_id, canal (site, Airbnb, etc), título, descrição (Nyra), preço, regras, disponibilidade (JSONB), published\_at
- `contracts`: tipo (aluguel, venda), partes (owner\_id, tenant\_id/comprador), status, `sign_url`, `signed_at`, `hash` (verificação)
- `payments`: contrato/reserva, gateway, moeda, valor, taxas, `tx_id`, `status`, `split` (JSONB), `receipt_url`

**Índices**

- Texto (pg\_trgm) em `listings.title/description`
- Vetores (pgvector) em embeddings de descrição para busca semântica (recomendação por similaridade)

## 3) Fluxos de automação (n8n) — “do lead ao dinheiro no banco”

## 3.1 Brann Realty (atendimento & triagem)

- **Disparo**: mensagens WhatsApp (Evolution) ou chat do site
- **Nós**:
	- Evolution Webhook → Normalize → Classifier (Flowise endpoint)
		- Intent router (compra, aluguel, temporada, venda do próprio imóvel)
		- Consulta DB (perfil do lead, cidade, budget)
		- **Recomendação**: busca semântica em `listings` (pgvector)
		- Resposta rica (carrossel/imagens + CTA)
		- Registro no CRM (Supabase) + evento no `audit_log`
		- Se documentação necessária: enviar **checklist auto** (PDF/Link)
- **Ações**:
	- Agendar visita (cria `booking` ou evento)
		- Encaminhar para Alphie se entrar em negociação/contrato

## 3.2 Nyra Realty (marketing & vitrines)

- **Disparo**: novo imóvel publicado, mudança de preço, fotos subidas
- **Nós**:
	- Geração de copy (Flowise LLM) + variações por canal
		- Tratamento de imagem (IA: upscale/limpeza; pode usar Replicate/SDXL local)
		- Montagem de **vídeo-tour curto** (template)
		- Publicações automáticas: Instagram, TikTok (via schedulers/integrações), Portais (quando API possível)
		- Atualização de `assets` e `listings`
- **Ações**:
	- Relatório semanal ao proprietário (performance dos anúncios)

## 3.3 Alphie Realty (contratos, pagamentos, relatórios)

- **Disparo**: lead qualificado, proposta aceita, aluguel recorrente, reserva confirmada
- **Nós**:
	- Geração de contrato (template + merge)
		- **Assinatura digital**: Clicksign/D4Sign (BR) ou DocuSign → gerar `sign_url` e monitorar callback
		- **Pagamentos**:
		- Cartão/Pix: **Pagar.me** (ou Mercado Pago)
				- Cartão internacional: **Stripe** (se necessário)
				- Cripto: **Coinbase Commerce** ou **NOWPayments**
				- Split automático (imobiliária x proprietário)
		- Emissão de recibo / nota (conector fiscal futuro)
		- Baixa financeira + repasse (agenda D+1/D+2)
		- Relatórios mensais (PDF/CSV) para proprietário
- **Ações**:
	- Lembretes automáticos (vencimento, multa, reajuste IGPM/IPCA)
		- Painel do proprietário (Supabase Auth + Dashboard)

## 3.4 Vistorias (inspections)

- **Disparo**: entrada/saída de inquilino, vistoria periódica
- **Nós**:
	- Form mobile/web (Upload fotos + checklist)
		- Classificação automática (detecção de danos com modelo visão)
		- Geração **Laudo PDF** (com fotos e carimbo de tempo)
		- Envio e arquivamento em `assets` + link no `contracts`
		- Notificações a ambas as partes

## 4) Pagamentos (BR & cripto) — decisões práticas

- **Pix + Cartão (BR)**: **Pagar.me** (split, recorrência, Pix fácil), alternativa Mercado Pago
- **Cartão intl / recorrência global**: **Stripe**
- **Cripto**: **Coinbase Commerce** (custódia simples) *ou* **NOWPayments** (mais moedas)
- **Estratégia**: centraliza webhooks em `api.ginkgorealtyhome.com/payments/webhook`, valida assinatura, registra em `payments`, atualiza `contracts` / `bookings`.

## 8) Segurança, LGPD & Compliance

- **Segredos**: `.env` cifrado; no servidor, usar `docker secrets` ou EasyPanel secrets
- **SSO admin**: Authelia/Keycloak para /admin (n8n, Flowise)
- **Criptografia**: TLS em tudo; dados sensíveis com `pgcrypto` quando necessário
- **RBAC**: papéis (admin, corretor, vistoriador, proprietário, auditor)
- **LGPD**: base legal (execução de contrato/consentimento), DPA com provedores, retenção e direito ao esquecimento
- **Auditoria**: `audit_log` + trilhas em n8n (Execution Logs)
- **Anti-fraude**: validação de documentos (Serpro/CPF/CNPJ — etapa futura), KYC para altos valores

---

## 9) Observabilidade & Resiliência

- **Logs**: Loki (ou Papertrail/Logtail), agregados por serviço
- **Métricas**: Prometheus + Grafana (dash: taxas de conversão, SLA de respostas, falhas de webhook)
- **Healthchecks**: Healthchecks.io para jobs críticos n8n
- **Backups**:
	- Postgres: snapshots diários + WAL a cada hora
		- Buckets (assets): versão + cópia fria mensal
		- Infra como código: Compose +.env no Git privado (sem segredos)
- **DR/Failover**: restauração ensaiada 1x/mês (playbook)

## 13) Decisões de engenharia (opiniadas)

- **Supabase Cloud** no início = velocidade total (Auth/Storage/DB/Realtime prontos). Se quiser 100% self-host, adote MinIO + Keycloak e Postgres próprio.
- **Pagar.me** é o trunfo no Brasil para **Pix + split**. **Stripe** entra para cross-border. **Coinbase Commerce** para cripto sem dor de cabeça.
- **Clicksign** resolve assinatura e validade jurídica no BR em 1h de integração.
- **n8n** como spina dorsal (retrys, filas, webhooks), **Flowise** foca na “consciência/roteamento” dos agentes.
- **pgvector** + embeddings de listings = recomendação que converte.
