## 1) Criar o projeto no Lovable

1. Vá em **Home → New Project**
2. Nome: **PYRE**
3. Escolha **Web App** (não só landing)
4. Se tiver opção, selecione um estilo “Clean / Modern / SaaS”

---

## 2) Prompt inicial (cola isso)

Cole este prompt como primeira instrução do projeto:

**PROMPT (base do produto):**

> Crie um app SaaS chamado PYRE. Ele é um “social media por assinatura”: gera conteúdo com IA (imagem/vídeo + legenda + hashtags), permite aprovar e agenda/publica automaticamente. Interface minimalista e premium.  
> Páginas: Landing, Pricing, Login/Signup, Dashboard.  
> No Dashboard: (1) Criar Conteúdo, (2) Biblioteca, (3) Calendário, (4) Conexões (Instagram/TikTok/X/Facebook), (5) Configurações de Marca (nicho, voz, cores, palavras proibidas).  
> Fluxo principal: Criar → Revisar/Aprovar → Agendar/Publicar.  
> Deixe preparado um módulo “Blotato Integration” em Conexões, com campos para API Key e Webhook URL e um botão “Test Connection”.

---

## 3) Ajustar a estética “Lumoo style”

Quando o Lovable gerar, peça um ajuste visual bem específico:

**PROMPT (design lumoo):**

> Ajuste o design para um layout inspirado em “Lumoo AI”: hero split (texto à esquerda, visual grande à direita), tipografia grande e limpa, espaçamento premium, fundo claro na landing.  
> Use cards com bordas suaves, grid minimalista, e um “product preview” grande na home.  
> CTA primário: “Conectar redes sociais”. CTA secundário: “Ver demo”.  
> Deixe a experiência elegante e simples, estilo SaaS europeu.

---

---

## 5) Montar o fluxo “Criar → Aprovar → Agendar”

No Dashboard, peça esse bloco central:

**PROMPT (fluxo MVP):**

> No Dashboard, implemente o fluxo principal:  
> Tela “Criar Conteúdo”: inputs (objetivo do post, tema, canal, data desejada, formato: imagem ou vídeo, CTA).  
> Botão “Gerar com IA” que cria: legenda, hashtags e um preview visual (placeholder se não tiver geração real).  
> Após gerar, enviar para tela “Revisão” com botões: Editar texto, Regenerar, Aprovar.  
> Ao aprovar, abrir modal “Agendar/Publicar”: escolher canal, data/hora, e botão “Enviar para Blotato”.

---

## 6) Área “Marca” (o que faz virar SaaS de verdade)

Isso é o que deixa replicável cliente após cliente.

**PROMPT (marca):**

> Crie a página “Marca” com um formulário de Brand Kit:  
> Nicho, público alvo, tom de voz, palavras obrigatórias, palavras proibidas, emojis permitidos, estilo de CTA, links fixos, cores (hex), fontes.  
> Salvar localmente (ou em storage simples do app).  
> O conteúdo gerado deve respeitar essas regras.

---

## 7) Conexões: preparar o “plug” do Blotato

Mesmo sem API real agora, já cria o painel certinho.

**PROMPT (blotato integration UI):**

> Na página “Conexões”, crie um card “Blotato” com campos: API Key, Webhook URL, Workspace/Account ID (opcional), e botão “Test Connection”.  
> Quando clicar “Test Connection”, envie um request POST de teste (payload JSON) para o Webhook URL e mostre o resultado (success/error).  
> Crie também toggles para canais: Instagram, TikTok, X, Facebook.

---

## 8) Payload padrão (o que o PYRE vai mandar)

Peça para o Lovable usar esse payload no “Enviar para Blotato”:

**PROMPT (payload):**

> No botão “Enviar para Blotato”, envie um POST para o Webhook URL com JSON:  
> {  
> "project":"PYRE",  
> "channel":"instagram|tiktok|x|facebook",  
> "scheduled\_at":"ISO\_DATETIME",  
> "caption":"...",  
> "hashtags":\["..."\],  
> "media":{ "type":"image|video", "url":"PLACEHOLDER\_OR\_UPLOAD\_URL" },  
> "brand":{ "voice":"...", "niche":"..." }  
> }  
> Mostre na UI um log da resposta.

---

## 9) Colocar “Biblioteca” e “Calendário” (pra parecer produto)

**PROMPT (biblioteca + calendário):**

> Crie a Biblioteca com lista de conteúdos gerados (status: draft/approved/scheduled/published).  
> Crie o Calendário com visual mensal/semanal mostrando posts agendados (pode ser simples).  
> Permitir clicar em um item para ver detalhes e editar/agendar de novo.
