## 🧠 O que é o MiroFish (visão direta)

O **MiroFish** é um projeto de IA open source focado em **simular o mundo real com múltiplos agentes inteligentes** para prever cenários futuros. [SourceForge+1](https://sourceforge.net/projects/mirofish.mirror/?utm_source=chatgpt.com)

Em vez de um único modelo (tipo ChatGPT), ele funciona como um **ecossistema inteiro de IAs interagindo entre si**.

---

## ⚙️ Como ele funciona (mental model simples)

Pensa assim:

> Você cria um **“universo digital paralelo”**  
> joga dados reais dentro  
> e deixa milhares de IAs “viverem” ali

### Estrutura básica:

- 🔹 Entrada: notícias, dados financeiros, políticas, textos
- 🔹 Motor: milhares de agentes com:
	- memória própria
		- personalidade
		- lógica de decisão
- 🔹 Execução: eles interagem entre si (tipo sociedade simulada)
- 🔹 Saída: um **relatório preditivo** com possíveis futuros

👉 Resultado: você consegue testar cenários tipo:

- “Se eu lançar esse produto, o mercado reage como?”
- “Se essa lei passar, o que acontece?”
- “Se o Bitcoin cair X%, o comportamento muda como?”
