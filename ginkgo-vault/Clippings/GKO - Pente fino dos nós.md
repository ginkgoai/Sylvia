Endpoint = a **Production URL** do seu MCP trigger.

Use o link mostrado no nó **MCP\_SUPABASE → MCP URL → Production URL** do workflow de cadastro.  
Formato:

```markdown
https://studio.ginkgosystems.tech/mcp/<WORKFLOW_ID>/exec
```

Exemplo (substitua pelo seu):

```markdown
https://studio.ginkgosystems.tech/mcp/afff95cc-9c5c-4a07-85f3-691e63d63601/exec
```

Defina assim no nó “MCP Supabase” do Agent:

- **Endpoint:** a URL acima.
- **Server Transport:** HTTP Streamable.
- **Authentication:** None.
- **Tools to Include:** Insert (ou All se quiser expor mais ações).

Payload esperado quando o agente chamar:

```markdown
{ "name": "Nome", "phone": "5599999999999", "email": "x@x.com", "plan": "Leaf Avançado", "source": "WhatsApp" }
```

certo, agora no mcp vamo simplificar e unir as funcoes e ferramentas, objetivos, ingetar documentos nas duas bases vetoriais e / cadastrar novos clientes, memorias curtas e longas. simples e funcional

Plano direto. Um único **MCP** com três ações: **registrar cliente**, **gravar memória** e **ingestar documento** nas duas bases vetoriais.

## 1) Payload único do MCP

Use este formato sempre que o Agent chamar o MCP:

```markdown
{
  "action": "register_client | add_memory | ingest_doc",
  "data": {}
}
```

### Exemplos

- Registrar cliente:
```markdown
{ "action":"register_client",
  "data":{"name":"Ana Lima","phone":"5551999999999","email":"ana@ex.com","plan":"Avançado","source":"WhatsApp"}}
```
- Memória curta/longa:
```markdown
{ "action":"add_memory",
  "data":{"user_id":"5551999999999","scope":"short","text":"Prefere voz Alex","tags":["voz","ptt"]}}
```
- Ingestão de documento (Docs) por URL:
```markdown
{ "action":"ingest_doc",
  "data":{"target":"docs","source_type":"url","url":"https://meusite.com/politica.pdf","title":"Política"}}
```
- Ingestão de texto direto para Memories long:
```markdown
{ "action":"ingest_doc",
  "data":{"target":"memories","scope":"long","source_type":"text","text":"Guia interno de atendimento","title":"Guia v1"}}
```

## 2) Fluxo MCP (n8n)

### Nó 1 — When Executed by Another Workflow

JSON example:

```markdown
{ "action":"register_client", "data":{} }
```

### Nó 2 — Validate & Normalize (Function)

```markdown
const a = ($json.action || '').trim();
const d = $json.data || {};

if (!['register_client','add_memory','ingest_doc'].includes(a)) {
  throw new Error('action inválida');
}

// normalizações
if (a === 'register_client') {
  if (!d.phone || !d.name) throw new Error('name e phone obrigatórios');
}
if (a === 'add_memory') {
  if (!d.user_id || !d.text) throw new Error('user_id e text obrigatórios');
  d.scope = (d.scope || 'short'); // short|long
}
if (a === 'ingest_doc') {
  if (!['docs','memories'].includes(d.target)) throw new Error('target deve ser docs|memories');
  if (!['url','text'].includes(d.source_type)) throw new Error('source_type deve ser url|text');
  if (d.source_type === 'url' && !d.url) throw new Error('url obrigatória');
  if (d.source_type === 'text' && !d.text) throw new Error('text obrigatório');
  d.scope = (d.scope || 'long'); // para memories
}

return [{ json:{ action:a, data:d } }];
```

### Nó 3 — Switch by action

- Case `register_client` → ramo A
- Case `add_memory` → ramo B
- Case `ingest_doc` → ramo C

---

## Ramo A — register\_client → Supabase REST

**HTTP Request (POST)**

- URL: `{{$env.SUPABASE_URL}}/rest/v1/brann_clients`
- Headers:
	```markdown
	apikey: {{$env.SUPABASE_SERVICE_ROLE}}
	Authorization: Bearer {{$env.SUPABASE_SERVICE_ROLE}}
	Content-Type: application/json
	Prefer: return=representation
	```
- Body (JSON):
```markdown
{
  "name":"={{$json.data.name}}",
  "phone":"={{$json.data.phone}}",
  "email":"={{$json.data.email || ''}}",
  "plan":"={{$json.data.plan || 'Não definido'}}",
  "source":"={{$json.data.source || 'Agent'}}"
}
```
- Resposta OK → **Return (Function)**:
```markdown
return [{ json:{ ok:true, action:'register_client', id:$json[0]?.id || null } }];
```

---

## Ramo B — add\_memory (memória curta/longa sem arquivo)

### B1) Create embedding (OpenAI Embeddings)

- Model: `text-embedding-3-large`
- Input: `={{$json.data.text}}`

### B2) Supabase insert (POST)

- URL: `{{$env.SUPABASE_URL}}/rest/v1/brann_memories`
- Headers: iguais ao ramo A
- Body:
```markdown
{
  "user_id":"={{$json.data.user_id}}",
  "scope":"={{$json.data.scope}}",
  "content":"={{$json.data.text}}",
  "metadata":{"tags":"={{$json.data.tags || []}}"},
  "embedding":"={{$json.data.embedding || $json.embedding || $json.data?.embedding || $json?.data || $json[\"data\"]}}"
}
```

> No n8n, mapeie o vetor vindo do node Embeddings para o campo `embedding`. Se o editor não suportar vetor direto, use **“Send Raw Body”** e serialize como array.

### B3) Return

```markdown
return [{ json:{ ok:true, action:'add_memory' } }];
```

---

## Ramo C — ingest\_doc (Docs ou Memories com URL/Text)

### C1) Fetch content (IF url)

- HTTP Request (GET) → `={{$json.data.url}}`
- Output: texto puro. Se PDF, use nó “PDF Extract” antes.

### C2) Select content (Function)

```markdown
const isUrl = $json.data.source_type === 'url';
const text = isUrl ? $json.page_text || $json.body || '' : $json.data.text;
if (!text) throw new Error('conteúdo vazio');
return [{ json:{ ...$json, content:text } }];
```

### C3) Embeddings (OpenAI)

- Model: `text-embedding-3-large`
- Input: `={{$json.content}}`

### C4) Supabase insert (POST)

- Se `target == 'docs'` → tabela `brann_docs`
- Se `target == 'memories'` → tabela `brann_memories` e respeitar `scope` de `$json.data.scope`

**URL:**

```markdown
{{$env.SUPABASE_URL}}/rest/v1/{{ $json.data.target === 'docs' ? 'brann_docs' : 'brann_memories' }}
```

**Body (JSON) quando docs:**

```markdown
{
  "content":"={{$json.content}}",
  "metadata":{"title":"={{$json.data.title || ''}}","source_type":"={{$json.data.source_type}}","url":"={{$json.data.url || ''}}"},
  "embedding":"={{...vector_from_embeddings_node...}}"
}
```

**Body (JSON) quando memories:**

```markdown
{
  "user_id":"={{$json.data.user_id || ''}}",
  "scope":"={{$json.data.scope || 'long'}}",
  "content":"={{$json.content}}",
  "metadata":{"title":"={{$json.data.title || ''}}"},
  "embedding":"={{...vector_from_embeddings_node...}}"
}
```

### C5) Return

```markdown
return [{ json:{ ok:true, action:'ingest_doc', target:$json.data.target } }];
```

## 4) No Agent

- **Tool:** `mcp_supabase`
- **Endpoint:** `https://studio.ginkgosystems.tech/mcp/<WORKFLOW_ID>/exec`
- **Schema de entrada que o Agent deve mandar:** os JSONs de exemplo acima.
- Instrução no System Prompt:  
	“Ao detectar dados de cliente, memórias ou documentos, chame `mcp_supabase` com `action` e `data` conforme o schema. Aguarde `ok:true`.”

Pronto. Simples e funcional.

Segue o mínimo para deixar **funcional** o MCP unificado (cadastro + ingestão em `GKO_DOCS` e `GKO_MEMORIES`).

---

## 1) Trigger

**When Executed by Another Workflow → JSON example**

```markdown
{ "action":"ingest", "data":{} }
```

---

## 2) Nó “Aiphe” (Function) — roteador e normalizador

```markdown
const a = ($json.action || '').trim();
const d = $json.data || {};

if (!['register_client','memory','ingest'].includes(a)) throw new Error('action inválida');

// validações mínimas
if (a==='register_client' && (!d.name || !d.phone)) throw new Error('name e phone obrigatórios');
if (a==='memory' && (!d.user_id || !d.text)) throw new Error('user_id e text obrigatórios');
if (a==='ingest') {
  d.target = d.target || 'docs';           // 'docs' | 'memories'
  d.scope = d.scope || 'long';             // só p/ memories
  d.source_type = d.source_type || 'gdrive';// 'gdrive' | 'url' | 'text'
  if (d.source_type==='gdrive' && !d.file_id && !d.file_name) throw new Error('file_id ou file_name obrigatório');
  if (d.source_type==='url' && !d.url) throw new Error('url obrigatória');
  if (d.source_type==='text' && !d.text) throw new Error('text obrigatório');
}

return [{ json:{ action:a, data:d } }];
```

## 3) Switch (action)

- `register_client` → **HTTP Supabase (insert brann\_clients)**
- `memory` → **Embeddings → GKO\_MEMORIES**
- `ingest` → **coleta conteúdo → chunk → embeddings → GKO\_DOCS/GKO\_MEMORIES**

## 4) Cadastro cliente (ramo register\_client)

**HTTP Request (POST)**

- URL: `{{$env.SUPABASE_URL}}/rest/v1/brann_clients`
- Headers:  
	`apikey: {{$env.SUPABASE_SERVICE_ROLE}}`  
	`Authorization: Bearer {{$env.SUPABASE_SERVICE_ROLE}}`  
	`Content-Type: application/json`  
	`Prefer: return=representation`
- Body:
```markdown
{
  "name":"={{$json.data.name}}",
  "phone":"={{$json.data.phone}}",
  "email":"={{$json.data.email || ''}}",
  "plan":"={{$json.data.plan || 'Não definido'}}",
  "source":"={{$json.data.source || 'Agent'}}"
}
```

---

## 5) Memória curta/longa (ramo memory)

- **OpenAI Embeddings**: `text-embedding-3-large`, input `={{$json.data.text}}`
- **GKO\_MEMORIES (ingest/upsert)**
	- `text`: `={{$json.data.text}}`
		- `metadata`: `={"user_id": $json.data.user_id, "scope": $json.data.scope || 'short', "tags": $json.data.tags || []}`
		- `embedding`: **saída do node de embeddings**

---

## 6) Ingestão de documento (ramo ingest)

### Coleta do conteúdo

- Se `source_type='gdrive'`
	- **Search files and folders**: query  
		`name = {{$json.data.file_name || ''}}` (ou use File ID direto)
		- **Download file**: ID do arquivo
- Se `source_type='url'`
	- **HTTP Request (GET)**: `={{$json.data.url}}`
- Se `source_type='text'`
	- **Function (make content)**:
		```markdown
		return [{ json:{ content:$json.data.text } }];
		```

### Normalizar conteúdo

**IF/Function antes de chunking**

- Quando vier de Drive/URL, extraia texto e gere `content`:
```markdown
const body = $json.body || $json.page_text || $json.data || '';
if (!body) throw new Error('conteúdo vazio');
return [{ json:{ ...$json, content: body.toString() } }];
```

### Chunk

- **Data Loader** → recebe `content`
- **Token Splitter**: `chunk_size=1000`, `overlap=200`

### Embeddings

- **OpenAI Embeddings**: input = **texto do chunk**

### Upsert

- **IF (`$json.data.target === 'docs'`)**
	- **GKO\_DOCS (ingest)**
		- `text`: chunk
				- `metadata`: `={"title": $json.data.title || '', "source_type": $json.data.source_type, "url": $json.data.url || ''}`
				- `embedding`: vetor
- **Else (`memories`)**
	- **GKO\_MEMORIES (ingest)**
		- `text`: chunk
				- `metadata`: `={"scope": $json.data.scope, "title": $json.data.title || ''}`
				- `embedding`: vetor
