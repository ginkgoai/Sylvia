## Visão rápida (mapa mental)

Lovable **não hospeda** → ele **aponta**  
Hostinger **hospeda DNS** → você **conecta**

É só DNS. Nada de FTP, VPS ou código.

## PASSO 1 — No Lovable (onde você já está)

1. Clique em **Publish** (canto superior direito).
2. Em **Add custom domain**, digite:
	- `ginkgosystems.tech`  
		ou
		- `www.ginkgosystems.tech` (recomendado)
3. Confirme.
4. O Lovable vai gerar **instruções de DNS** (geralmente CNAME).

⚠️ **Não feche essa tela** ainda.

---

## PASSO 2 — Hostinger (DNS)

1. Acesse o **hPanel da Hostinger**
2. Vá em:
	```markdown
	Domínios → ginkgosystems.tech → DNS / Editor de Zona DNS
	```

---

## PASSO 3 — Criar os registros DNS

### Caso mais comum (CNAME)

No editor DNS, adicione:

### 🔹 CNAME

| Campo | Valor |
| --- | --- |
| Tipo | CNAME |
| Nome | `www` |
| Aponta para | `published-url.lovable.app` *(ou o que o Lovable mostrar)* |
| TTL | Padrão |

Depois disso:

### 🔹 Redirecionar domínio raiz (opcional mas recomendado)

Se quiser que `ginkgosystems.tech` vá para `www.ginkgosystems.tech`:

- Use **Redirecionamento** na Hostinger  
	ou
- Adicione A Record conforme instrução do Lovable (se houver)

---

## PASSO 4 — Voltar ao Lovable

1. Volte na tela de **Publish**
2. Clique em **Verify / Check DNS**
3. Aguarde validação (pode levar de **2 a 30 min**, às vezes até 1h)

Quando validar → **Publish final**

## FAÇA ISSO AGORA (passo a passo exato)

### 1️⃣ Clique em Manual setup

Ignore login social. Você não precisa trocar conta.

---

### 2️⃣ O Lovable vai mostrar os registros DNS

Normalmente ele pede **CNAME** assim:

```markdown
Type: CNAME
Host/Name: www
Value/Target: published.lovable.app
```

⚠️ Copie **exatamente** o valor que ELE mostrar (pode variar).

---

### 3️⃣ Vá para a Hostinger (hPanel)

Caminho:

```markdown
Domínios → ginkgosystems.tech → DNS / Editor de Zona DNS
```

---

### 4️⃣ Crie o registro CNAME

No editor DNS:

**Adicionar novo registro**

| Campo | Valor |
| --- | --- |
| Tipo | CNAME |
| Nome | `www` |
| Aponta para | valor que o Lovable deu |
| TTL | Auto / Padrão |

➡️ Salvar.

---

### 5️⃣ (Recomendado) Redirecionar domínio raiz

Para evitar SEO quebrado:

- Redirecione  
	`ginkgosystems.tech` → `www.ginkgosystems.tech`

Na Hostinger:

```markdown
Domínios → Redirecionamentos
```

---

### 6️⃣ Volte ao Lovable

- Clique em **Verify / Check DNS**
- Aguarde **5–30 minutos**
- Quando validar → **Publish**

SSL (HTTPS) entra automático depois.
