# LEAF BY GINKGO — PROMPTS OPERACIONAIS PARA FABLE + CLAUDE DESIGN

## Ordem de execução

1. Crie um projeto novo no Claude Design.
2. Anexe `LEAF_DESIGN.md`.
3. Envie o Prompt 01.
4. Revise o sistema visual antes de gerar a campanha.
5. Anexe `LEAF_META_CAMPAIGN_SYSTEM.md`.
6. Execute os prompts por lote.
7. Exporte as peças aprovadas.
8. Não misture este projeto com outras marcas.

---

## Prompt 01 — Scaffold do sistema

Crie um sistema de design completo a partir do arquivo LEAF_DESIGN.md.

Entregue:
- tokens;
- paleta;
- tipografia;
- grid;
- botões;
- cards;
- chips;
- componentes de conversa;
- cards de módulos;
- diagramas de fluxo;
- templates 4:5, 1:1 e 9:16;
- página de revisão visual.

Não gere a campanha ainda. Primeiro, apresente o sistema para aprovação.

---

## Prompt 02 — Biblioteca de criativos

Agora crie uma biblioteca reutilizável para campanhas do LEAF BY GINKGO.

Inclua:
- template “problema operacional”;
- template “bot vs agente”;
- template “conversa demonstrativa”;
- template “módulos”;
- template “founder demo”;
- template “antes/depois”;
- template “prova de produto”;
- template “retargeting”.

Todos os templates devem aceitar troca de headline, screenshot e CTA sem quebrar o layout.

---

## Prompt 03 — Lote orgânico

Use o conteúdo de `LEAF_META_CAMPAIGN_SYSTEM.md`.

Gere os 12 posts orgânicos em formato 4:5.

Para cada post:
- aplique uma composição diferente;
- preserve o mesmo sistema;
- limite o texto no criativo à headline e uma linha de apoio;
- coloque a legenda completa separadamente;
- mantenha o CTA visível nos posts de conversão;
- use interfaces ou diagramas coerentes com o tema.

---

## Prompt 04 — Carrosséis

Gere os três carrosséis do arquivo de campanha.

Regras:
- sete slides por carrossel;
- slide 1 com headline forte;
- slides intermediários com uma ideia cada;
- último slide com CTA;
- numeração discreta;
- consistência de navegação;
- legibilidade total em celular;
- progressão narrativa clara.

---

## Prompt 05 — Meta Ads

Crie seis anúncios de conversão:
1. Seu WhatsApp fecha.
2. Não é um bot.
3. Modelo modular.
4. Demonstração.
5. Handoff humano.
6. Retargeting.

Para cada anúncio:
- versão 4:5;
- versão 1:1;
- headline A;
- headline B;
- composição A orientada à dor;
- composição B orientada ao produto;
- CTA “Solicitar demonstração”;
- mensagem pré-preenchida para WhatsApp.

---

## Prompt 06 — Stories/Reels

Crie três sequências verticais 9:16 com 8 a 15 segundos.

Entregue:
- storyboard;
- keyframes;
- texto por cena;
- transições;
- indicação de movimento;
- versão estática de cada frame;
- CTA final.

O movimento deve representar atividade operacional: mensagens entrando, base sendo consultada, dados organizados e módulos sendo conectados.

Não usar partículas aleatórias, explosões neon ou animações decorativas sem função.

---

## Prompt 07 — Founder demo

Crie um template de founder demo para Gabriel Schaun apresentar o LEAF.

Composição:
- fundador em 35% da tela;
- produto ou conversa em 65%;
- headline curta;
- legenda grande;
- assinatura “Built in Brazil. Designed for global operations.” apenas em versões institucionais;
- versão PT-BR para Facebook;
- CTA para demonstração.

O fundador deve parecer operador e arquiteto do sistema, não influenciador genérico.

---

## Prompt 08 — Revisão crítica

Atue como diretor de criação, estrategista de performance e designer de produto.

Avalie cada peça de 0 a 10 em:
- clareza;
- interrupção;
- legibilidade;
- credibilidade;
- diferenciação;
- prova visual;
- coerência com o LEAF;
- força do CTA.

Reprojete qualquer peça abaixo de 8.

---

## Prompt 09 — Exportação

Prepare exportações finais.

Estrutura:
- 4:5 em alta resolução;
- 1:1;
- 9:16;
- JPG para imagens;
- MP4 para animações;
- arquivos fonte editáveis;
- nomes conforme o padrão do DESIGN.md;
- relatório com copy, CTA, campanha e versão.

Crie também uma capa de biblioteca chamada:
**LEAF BY GINKGO — META CAMPAIGN SYSTEM V1**
