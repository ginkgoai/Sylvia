The Agentica SDK skill provides a comprehensive framework for developing sophisticated AI agents in Python. It enables developers to transform standard functions into AI-powered tools using the @agentic decorator, spawn autonomous agents with specific premises, and manage complex multi-agent orchestrations. With built-in support for the Model Context Protocol (MCP), token usage tracking, conversation persistence, and OpenTelemetry tracing, this skill is essential for building production-grade AI applications that require structured outputs, tool-use, and robust state management.

## Key Features

01Seamless Model Context Protocol (MCP) integration for connecting external tools

02Asynchronous agent spawning with custom system prompts and model selection

03Support for multi-agent coordination and persistent state across conversation history

04Advanced token management including usage tracking and fine-grained limits

05@agentic decorator for creating AI-powered Python functions with minimal boilerplate
