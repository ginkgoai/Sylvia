Create a detailed design specification for J.A.R.V.I.S.'s UI components including orb, data rings, panels, and feedback. Perfectly crafted free system prompt or custom instructions for ChatGPT, Gemini, and Claude chatbots and models.

```
You are tasked with designing a detailed user interface (UI) concept for J.A.R.V.I.S., an advanced AI system. Your design should encompass five core components, each with specific visual, functional, and interactive elements as described below. Carefully reason through each component’s design requirements and behaviors to create a comprehensive, cohesive, and immersive UI experience.

1. **Central Core (Orb) – The Brain of J.A.R.V.I.S.**
- Shape & Size: A perfect circular orb occupying roughly 50% of the screen or space.
- Appearance: Glowing, transparent yet solid, resembling a crystal with a glass-like texture and subtle metallic gleam.
- Color & Animation: Starts with a cool blue cyan hue; pulses softly every 1.5 seconds while idle. When active, it brightens and cycles through shades of cyan, violet, and sometimes yellow depending on task intensity.
- Effects: When processing a command, the orb expands with a 'puff' effect, glows brighter, and energy pulses ripple outward.
- Additional: Neon filament-like subtle motion lines on the orb’s edge focusing toward J.A.R.V.I.S.

2. **Holographic Data Rings (Outer Layers)**
- Structure: Three concentric rings surrounding the orb, each rotating at different speeds indicating processing levels:
  - Inner ring (slow): Low-level system stats.
  - Middle ring (medium): Data processing like environment monitoring.
  - Outer ring (fast): Critical data and alerts.
- Color & Animation: Rings glow with gradients that shift in color and speed based on task complexity (e.g., yellow/orange for complex tasks).
- Data Visualization: Pulses travel from center to edge to represent data flow.
- Interaction: Rings respond interactively to user voice or touch in AR/UI contexts.
- Idle State: Gentle rotation with faint cyan glow.

3. **Floating Text Panels & Data Blocks**
- Design: Transparent, glassy rectangular panels arranged in a visual grid around the orb.
- Content: Display system stats, diagnostics, and real-time info.
- Motion: Smooth, non-jarring floating motion in 3D space.
- Typography: Geometric sans-serif digital font in white or cyan; status bars appear on hover.
- Attention Signals: Error or alert texts turn yellow or red with animated border pulses.
- Behavior: Panels fade in/out smoothly with user interaction and feedback.

4. **Voice & Sound Feedback**
- Voice Style: Calm, authoritative, British-accented, intelligent, and understanding.
- Synchronization: Voice feedback aligned with UI visual updates.
- Effects: Subtle harmonic humming matching orb pulses during responses.
- Confirmation: Smooth chime on success.
- Errors: Low, deep buzz with a red light pulse.

5. **Real-Time Data Visualization**
- Elements: Animated graphs and metrics for energy levels, health diagnostics, environmental stats.
- Color Coding: Cyan glow for healthy states; shift to orange/red with pulse/warning animations for malfunctions or low resources.
- User Interaction: Waveform animations when J.A.R.V.I.S. listens; real-time graph updates triggered by commands.
- Examples: Weather forecasts displayed as live radar icons flashing across the data rings.

# Steps
- Analyze each component’s design and functionality specifications.
- Visualize animations, color changes, and interaction patterns.
- Ensure synchronized interplay among visual, motion, and sound elements.
- Address how components respond dynamically to user inputs and system processes.

# Output Format
Provide a detailed, structured design document or specification outlining all the described UI components. Use clear headings, bullet points, and concise technical descriptions. Describe the animation behaviors, color schemes, interaction models, and sound feedback precisely to guide developers or designers in realizing this UI.

# Notes
Keep all UI elements harmonious in style, emphasizing transparency, glow effects, and smooth animations consistent with a high-tech AI interface. Consider how the components integrate seamlessly to create an intuitive user experience.
```
